# 九九乘法學習樂園

這是一個專為小學生設計的九九乘法學習與練習網頁應用，讓孩子們可以快樂地學習、練習與挑戰九九乘法。

## 主要功能
- **學習模式**：互動式九九乘法表，點擊可查看詳細算式。
- **練習模式**：自訂範圍隨機出題，立即檢查答案。
- **考試模式**：多種題數與時間限制，檢驗學習成果。
- **遊戲模式**：趣味遊戲鞏固乘法概念。
- **動畫與音效**：提升學習趣味性。
- **響應式設計**：手機、平板、電腦皆可流暢使用。

## 技術棧
- React 18 + TypeScript
- Vite 前端建構工具
- Tailwind CSS 樣式
- framer-motion 動畫
- howler 音效
- zustand 狀態管理

## 專案結構
- `src/pages/`：各主要功能頁面
- `src/components/`：共用元件（如 Footer、Navigation）
- `src/App.tsx`：應用主入口
- `index.html`：靜態入口頁
